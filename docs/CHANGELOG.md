# Changelog

## 2026-10-16

### CMS → 簽到管理操作頁面

- 三個操作頁面的頂部返回按鈕統一為左箭頭圖示加「返回」。

- 參與名單、電郵邀請記錄及簽到記錄拆為獨立頁面，由簽到管理列表直接進入。
- 參與名單頁的返回、保存及發布按鈕統一置頂，場次選擇放在標題區下方；保存可確認待存的分枱安排。

### CMS → 電子邀請函及電郵配置

- 邀請函及電郵預覽以配置文案顯示資料，移除重複的固定人員、場次、時間、地點及座位資訊區，保留標題、背景圖與二維碼。

- 電子邀請函增加紅金色背景圖預覽，保留清晰文字底板及二維碼；上傳背景圖後優先使用自訂圖片。

- 預設文案加入姓名、活動名稱、場次、簽到時間、地點、枱號及座位動態欄位，預覽自動帶入個人資料；自訂文案保留，不分組時隱藏枱號及座位行。

### CMS → 簽到管理、抽獎管理及活動統計

- 場次配置加入統一垃圾桶刪除按鈕，至少保留一個場次；已有參與名單的場次不可直接刪除。

- 簽到預設兩個場次，可新增場次；每個場次可獨立配置場次名稱、簽到開放及截止時間，地點、分組方式、邀請函及電郵配置共用，既有名單保留於第一場次。
- 各場次自行導入名單，跨場次重複員工或電郵不可加入；名單、分枱、電郵及核銷按場次管理。
- 未簽到人員可調整場次，清除原座位並更新二維碼，已發送邀請標記待重發；已簽到人員不可調整場次。
- 邀請函顯示場次資料，二維碼綁定人員及場次，跨場次掃碼提示場次不符。
- 抽獎增加來源場次選擇；活動統計及明細支援全部場次或指定場次查看。

### CMS → 抽獎管理

- 每個獎項右側增加統一樣式的垃圾桶刪除按鈕（滑過顯示「刪除獎項」）；保存時至少保留一個獎項，已有抽獎結果時沿用獎項鎖定限制。

- 新增「按枱抽獎／全場抽獎」模式；原抽獎預設為全場抽獎。
- 按枱模式可選簽到活動及參與枱號，各獎項設定獎項名稱、獎品及每枱中獎人數，顯示預計總名額。
- 支援僅限已簽到人員、跨獎項重複中獎設定；未分枱人員不參與按枱抽獎，同一獎項不重複中獎。
- 每枱資格人數不足時確認按實際人數抽取，不從其他枱補人；結果保留枱號、字母座位、獎項及獎品。
