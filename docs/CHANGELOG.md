# Changelog

## 2026-09-22

### APP → 活動詳情／投票 → 晉級結果統計中

- 新增「投票已截止」缺省頁，顯示「投票結果統計中」，下方顯示下一階段投票開始時間，不顯示預計公布時間。
- 預覽示例中，第一個投票可直接查看結果（票數、佔比及排名）；最後一個投票顯示統計中狀態，其餘投票保持原有顯示。
- 投票列表保留已截止投票的候選內容：已選候選項只標示「已選」，未選候選項不顯示底部按鈕。
- 底部顯示「已截止」「投票結果統計中」及下一階段投票開始時間；示例時間為 2026-03-03 18:00，實際投票按下一階段設定顯示。
- 投票走勢切換至最後一個投票時，顯示「投票已截止，投票結果統計中」及下一階段開始時間的缺省頁；第一個投票展示可查看結果的示例，其餘投票走勢維持原有顯示規則。
- 缺省頁沿用活動背景及字體；提供統計中狀態的預覽示例。


### CMS → 投票管理 → 新增／編輯 → 投票階段配置

- 第一階段去掉「晉級規則配置」。
- 第二階段及之後，勾選晉級規則後顯示預留 5 分鐘處理時間的提示；未設定來源時，預設選擇上一階段。
- 勾選晉級後，本階段投票最早於上一階段結束 5 分鐘後開始；不符合時顯示提示，並阻止保存草稿及發布。
- 投票開始時間、結束時間移至晉級規則配置下方，支援選擇日期及時分秒。
- 去掉「從上一階段導入前 N 名」按鈕。
- 去掉「最早開始時間」文字，保留規則提示及時間錯誤提示。
