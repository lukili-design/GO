# v1.1 版本變更摘要

日期：2026-10-23。基於 v1.0，僅納入已提出的功能修改及交接文件結構整理；未改變原抽獎、名額、寄信決策。

| 需求 | v1.0 | v1.1 | 驗收／遷移影響 |
|---|---|---|---|
| CSV-01、CSV-02 | 簽到 CSV 四欄，列表無公司 | 部門後新增公司；五欄模板，相容舊四欄 | AT-27；company 可空，歷史資料顯示 —，抽獎專用模板不強制改版 |
| MAIL-09 | 預約資訊附在最近發送時間內 | 新增獨立預計發送時間，優先個別預約，再取未發送人員未來統一時間 | AT-28；成功發送與預計時間分開，不偽造成功時間 |
| MAIL-03 | 發送／重發已勾選（人數） | 發送/已勾選(人數) | 人數動態更新；原時間確認彈窗與寄信規則不變 |
| 文件 | 三份詳細文件分開閱讀 | 增加一份完整 PRD 閱讀版、狀態矩陣及需求追蹤表 | 研發可從單一文件完整閱讀；詳細源文件保留供維護 |

範圍外：本版不新增失敗一鍵重發、作廢重抽或自助取消報名。原有 26 項驗收保留，新增 2 項，共 28 項。

發佈標籤、提交 SHA、研發完成日期及部署狀態尚未建立，不預填。本版號為需求交接版本，不代表系統已上線。

本版文件修訂：已確認規則直接合併至功能章節，新增人員與電郵欄位表；PRD 移除確認紀錄章節，移除用戶指定的「本期不包含範圍」清單。業務規則不變。
