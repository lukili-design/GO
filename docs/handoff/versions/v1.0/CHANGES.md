# v1.0 交接摘要

日期：2026-10-23。首次完整需求基線，沒有上一版可比較。

## 涵蓋範圍

活動基本配置、CMS 簽到及抽獎、APP 活動、邀請函、電郵與抽獎大屏；投票僅涵蓋關聯入口。包含 26 個驗收案例。

## 本版關鍵決策

- 正式開獎只由 CMS 操作，大屏同步展示。
- 揭曉即正式生效；確認只進入下一輪，斷線不得重抽。
- 關閉公開只隱藏公開名單，本人仍可看結果。
- 同活動每人只參加一場；所有來源共用場次名額，留空不限。
- APP／CSV 成功後自動生成邀請函；未到統一寄信時間加入批次，時間已過或未設定則由管理員安排發送。
- 同場次按枱抽獎座位號永不重複。

## 實作與驗收影響

必須對照 IMPLEMENTATION 的演示差異，補齊服務端儲存、身份、名額併發、核銷、郵件排程及大屏同步。現有演示不代表上述正式能力已完成。完整驗收見 SPEC 的 AT-01 至 AT-26。

## 交付基線

此版文件與演示代碼需由用戶一併提交推送。本摘要不預填尚未建立的提交 SHA、Git 標籤或部署狀態。
